## EngSense

For non-trivial software-engineering judgment—code review, refactoring, architecture, API design, abstraction, maintainability, testability, or engineering trade-offs—use the installed `engsense` Skill.

Prefer repository evidence, preserve behavior/compatibility/specialist invariants, and load only the EngSense modules relevant to the current decision. Do not invoke EngSense for mechanical formatting, trivial renames, or deterministic lint fixes.
